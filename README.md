# 🇰🇿 ИИ-Поисковик законов Республики Казахстан (Прототип)

Смарт-поисковик правовых норм и статей законодательства РК по обычному текстовому описанию жизненной ситуации.

Проект создан для демонстрации работы векторного поиска (RAG) и обработки естественного языка (NLP) на базе Python и LangChain.

---

## 💡 Как это работает?

Вместо сложного юридического языка и точного знания номеров статей пользователь может описать ситуацию своими словами (например: *«купил смартфон, а у него не работает экран, магазин не меняет»* или *«сосед повредил имущество»*). 

Система:
1. Анализирует смысл описания с помощью векторных эмбеддингов (`sentence-transformers`).
2. Сопоставляет его с базой нормативно-правовых актов РК.
3. Выдает наиболее подходящие законы, статьи, возможные уточняющие вопросы и ссылки на официальную ИПС «Әділет».

---

## 🛠️ Технологический стек

* **Язык:** Python 3.10+
* **Фреймворк:** LangChain
* **Векторное хранилище:** ChromaDB
* **Модель эмбеддингов:** `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (поддержка русского и казахского языков)
